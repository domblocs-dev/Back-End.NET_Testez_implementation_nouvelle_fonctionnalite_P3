# Back-End.NET_Testez_implementation_nouvelle_fonctionnalite_P3

## Afin d'exécuter l'application en local dans la branche dev:
- Cloner le dépot
- git fetch origin + git checkout -b dev origin/dev + git pull
- Sous Visual Studio 2026, sélectionner P3AddNewFunctionalityDotNetCore comme projet de démarrage
- Lancer l'application sans débogage
- sélectionner P3AddNewFunctionalityDotNetCore.Tests
- Lancer les tests unitaires et d'intégration
